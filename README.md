# Retail Sales Analysis Project

## Overview

This project analyzes retail sales data using Python, Pandas, SQL, and Matplotlib. The objective was to clean and prepare the data, perform business analysis, generate insights, and create visualizations that support decision-making.

## Analysis Performed

### Data Cleaning

* Converted date columns to datetime format
* Corrected data types
* Created a YearMonth field for time-series analysis

### Exploratory Data Analysis

* Top Customers by Profit

### Visualizations

* Sales by Category

* Top Profit Customers

## Key Findings

* Technology generated the highest sales and profit.
* The West region achieved the highest profit margin.
* Tables and Bookcases were the primary loss-making sub-categories.
* Regions with higher discounts tended to have lower profitability.
* A small group of customers contributed significantly to overall profit.
