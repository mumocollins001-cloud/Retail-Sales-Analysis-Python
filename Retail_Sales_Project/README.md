# Retail Sales Analysis Project

## Project Overview

This project analyzes retail sales data to identify sales trends, profitability drivers, customer performance, and regional business performance.

The analysis was conducted using Python, Pandas, SQL, and Matplotlib.

---

## Tools Used

* Python
* Pandas
* PandasQL
* Matplotlib
* Excel

---

## Business Questions Answered

1. Which product categories generate the highest sales?
2. Which categories generate the highest profit?
3. How do sales change over time?
4. Which regions are most profitable?
5. Which sub-categories are generating losses?
6. Who are the most profitable customers?

---

## Key Findings

* Technology generated the highest sales and profit.
* Sales increased steadily from 2014 to 2017.
* The West region achieved the highest profit margin.
* The Central region had the lowest profit margin and highest discounts.
* Tables and Bookcases were loss-making sub-categories.
* A small group of customers generated a large share of total profit.
